## Key concepts

- **Two accounts for IT staff:** normal for daily work, `adm-` for admin tools. A phished normal account doesn't give admin rights.
- **Least privilege:** managers approve but get no admin account; only one person in Domain Admins; Service Desk gets delegated rights, not Domain Admin.
- **OU = where** an account lives · **Department = information** about the person.
- **Canonical name** (path, left to right) vs **Distinguished name** (right to left, used by PowerShell and LDAP).
- **New starter = Request.** Ask the manager first; disable until the start date; **never email passwords**.
- **Contractors:** separate OU, expiry date, a manager to ask.
- **Permissions to groups, never to people** (`GG_IT_Read`). Staff = Modify, read-only = Read & execute.
- **Pending** status = waiting for someone or something, not stuck.
