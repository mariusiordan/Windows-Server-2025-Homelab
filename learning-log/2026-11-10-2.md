## Key concepts

- **Test that the wrong thing fails:** Kevin's "Access denied" when creating a file is the proof he's read-only.
- **In person, check the badge** — faster and stronger than calling the manager.
- **Always check the lockout status before a reset.** A reset without an unlock still fails, and the user thinks the new password is wrong.
- **"Must change password at next logon":** the technician never knows the user's real password.
- Give a temporary password in person and let the user log in **straight away** — no sticky notes.
- A **kind user note** (a passphrase tip) prevents the next ticket.
- **Leaver = disable, don't delete.** Ask the manager **when** and **why** — friendly leavers at the end of the day, dismissals immediately.
- **AD is the source of truth.** Disabling a user in GLPI only blocks the helpdesk.
- **Escalating to L2 is part of the process**, not a failure.
