## Key concepts

- **Two doors:** share + NTFS permissions — the most restrictive wins.
- **Least privilege:** users get Modify, never Full control.
- **Mover process:** add the new access **and remove** the old one (avoid privilege creep).
- New group membership loads **at login** — the user must log off and on.
- GLPI timeline: **Follow-up** (talking) · **Task** (working) · **Solution** (finished).
- Solution text: **Cause → Fix → Verification → User note**.
